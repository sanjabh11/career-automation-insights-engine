Method

ECE is computed by binning APO estimates, averaging predicted exposure and observed external anchors in each bin, and summing each bin's weighted absolute gap. The Edge Function now uses apo_overall_vs_expert_assessments and joins apo_logs.occupation_code to expert_assessments.occupation_code.

Limitations

  • External anchors are published computerisation probabilities, not contemporary expert labels for generative AI exposure.
  • The fixture uses a small set of occupations to verify plumbing and artifact serving, not to certify model accuracy.
  • Live calibration requires applying the migration, running APO jobs for matched occupations, and running the calibrate-ece function in an approved Supabase environment.
